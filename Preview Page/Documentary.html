Architecture Overview

Escape Of Matrix (E.O.M) is a state-of-the-art local-first application designed to gamify every element of your life. By combining modular components with an RPG progression system, you can build positive habits, manage transactions, log workouts, and track progress under one private workspace.

💡 Privacy First Principle
Your data never leaves your device. E.O.M uses a synchronized local storage layer bound to a Zustand state manager. Backup files are exported to your local file system directly.

The core codebase is structured as a single-page React application powered by Vite, with multi-platform wrappers:

  • Vite + React: Handles responsive rendering, dynamic components, and reactive states.
  • Zustand: Directs user state, transaction ledgers, workout logs, habit histories, and AI parameters.
  • Capacitor (iOS): Transpiles and syncs front-end code directly into an iOS-native Xcode build for iPhone compatibility.
  • Electron: Provides cross-platform desktop shells for macOS and Windows.

Quick Start & Setup

Set up the development environment on your local macOS workstation:

Prerequisites

Ensure you have Node.js (v18+) and npm installed. Check by running:

node -v
npm -v

Installation Steps

1. Clone the project and navigate into the workspace directory:

git clone https://github.com/FRX132/E.O.M.git
cd E.O.M

2. Install package dependencies:

npm install

3. Launch Vite development mode:

npm run dev

The application is now hosted locally, usually at http://localhost:5173.

AI Connection & MCP Router

E.O.M features an intelligent AI Assistant Panel which acts as an intent parser. It processes natural language and translates your statements into app states through our Pseudo-MCP router.

Configuring Providers

You can connect several types of AI backend servers in the Connection Settings Hub inside the Assistant panel:

  1. Local Client (Transformers.js): Run lightweight models directly inside a background Web Worker in your browser. Zero-cost, 100% offline.
  2. Ollama: Run models locally. Direct prompts to:
    http://localhost:11434/api/generate
  3. LM Studio: Route execution to local OpenAI-compatible endpoints:
    http://localhost:1234/v1
  4. OpenAI / Anthropic: Connect global cloud models by providing API keys.

MCP Commands & Prompts Router

The app uses a keyword-based syntax parser to map prompt texts to Zustand actions. Here is a quick reference table of active commands:

Intent Route Keywords Matched Result / Action Taken Example Prompt
LOG_WORKOUT workout, training, gym, log Logs a target workout to the fitness calendar. "log chest workout for 45 mins"
COMPLETE_GOAL complete, check off, fertig Marks an active goal as completed and awards XP. "complete goal read React docs"
ADD_GOAL goal, add, neu, ziel Adds a new goal to the weekly list. "add goal write portfolio code"
DELETE_ITEM delete, remove, expense, loeschen Deletes a matching expense item or clear a list index. "delete expense subscription"
⚠️ Router Order Notice
The intent router matches COMPLETE_GOAL prior to ADD_GOAL to prevent wildcard requests from adding new goals rather than checking them off.

Finance Hub & Performance Memoization

The Finance Hub (Expense Tracker) is built to manage capital entries, monthly recurring subscriptions, budgets, and net worth tallies.

iPhone Input Typing Lag Fix

In webview wrappers (like Capacitor on iOS), re-rendering huge lists on every single keystroke causes CPU spikes, making text input extremely laggy. E.O.M uses a multi-tier optimization strategy to prevent this:

⚡ Performance Implementation Details
  • Local Key-State Bounds: Input values write to local component states (e.g. useState) on keystroke.
  • Deferred Store Sync: Zustand store writes are deferred until onBlur or Enter key presses, keeping inputs lag-free.
  • React.memo Subcomponents: Rows are extracted into <ExpenseRow> and <AssetRow> wrapped in useMemo, eliminating unnecessary calculations.
  • Key-Based Reset Sync: A hash combination (e.g. key={id-name-amount}) is bound to rows, allowing values to sync automatically when changed externally without firing side-effects.

Anatomical Muscle Map

The Workout Hub displays an interactive anatomical model. Clicking a muscle group lets you register exercise sets, view muscle stress levels, and get custom sport recommendations.

Technical Details

  • Dual Anatomy SVGs: Integrated path bindings representing male and female body vectors.
  • Smart Synchronization: Muscle maps load the appropriate vector based on the profile gender setting.
  • Zustand Integrations: Registered workouts automatically update the main calendar, granting progress logs.

Capacitor & iOS Xcode Guide

Deploying your React code to run native 1:1 on your iPhone or simulated Apple environment:

Step-by-Step Compile Workflow

1. Open your terminal in the workspace directory and build the production bundle:

npm run build

This creates static HTML, JS, and CSS resources inside the dist/ directory.

2. Copy the files into the Xcode native project:

npx cap sync ios

3. Launch Xcode and compile:

npx cap open ios
⚠️ Bundle Sync Required
Always run npm run build && npx cap sync ios after modifying React components to update the native iOS project files.

Platform Troubleshooting

Here are some common platform issues when building E.O.M:

Electron API Blocks in Web and iOS

E.O.M contains desktop features like PDF backups that use window.electronAPI. In Web browsers or iOS WebViews, this will throw an undefined error. 

// Safe API execution pattern
if (window.electronAPI) {
    window.electronAPI.backupData(payload);
} else {
    console.log("Running in non-desktop client: Fallback to local storage export.");
    // Web/Capacitor backup export logic
}
